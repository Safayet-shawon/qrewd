# Character models (optional)

Put your own character models here:

- `girl.glb` — the girl
- `boy.glb` — the boy

If a file is missing, the museum uses its built-in procedural characters.

A model should be a standard glTF/GLB file. Animation clips whose names contain
`idle` and `walk` (or `run`) are played automatically. Models are scaled to about
1.7 m tall, standing on the floor. Use only models you have the right to use.
